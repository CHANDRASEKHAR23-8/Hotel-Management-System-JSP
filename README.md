\# Hotel Management System using JSP



\## Project Overview

The Hotel Management System is a web application developed using Java Server Pages (JSP) and Java Servlets.



\## Technologies Used

\- Java

\- JSP and Servlets

\- HTML and CSS

\- Apache Tomcat 9

\- Eclipse IDE

\- Oracle Database 10g (if configured)



\## Software Requirements

\- JDK

\- Eclipse IDE for Enterprise Java and Web Developers

\- Apache Tomcat 9

\- Oracle Database 10g (if required by the project)



\## Installation and Execution



\### 1. Clone the Repository



```bash

git clone https://github.com/CHANDRASEKHAR23-8/Hotel-Management-System-JSP.git

```



\### 2. Import into Eclipse

1\. Open Eclipse.

2\. Select File → Import.

3\. Choose General → Existing Projects into Workspace.

4\. Select the project folder and click Finish.



\### 3. Configure Tomcat

1\. Open Window → Show View → Servers.

2\. Configure Apache Tomcat 9 if it is not already configured.

3\. Add the project to the Tomcat server.



\### 4. Run the Application

1\. Right-click the project in Eclipse.

2\. Select Run As → Run on Server.

3\. Select Tomcat v9.0 Server at localhost.

4\. Click Finish.



\### 5. Open in Browser



```text

http://localhost:8080/Hotel/

```



Replace `Hotel` with your actual project context root if different.



\## Troubleshooting

\- \*\*404 Error:\*\* Check the context root and deployed JSP files.

\- \*\*Tomcat Error:\*\* Check the JDK configuration and Eclipse Console.

\- \*\*Database Error:\*\* Verify the database connection settings if Oracle is used.
